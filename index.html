01. Konsep Dasar

Mengenal Perkakas TIK

💡 Perkakas TIK adalah perangkat keras (hardware) maupun lunak (software) yang digunakan untuk menerima, mengolah, menyimpan, menyampaikan, atau bertukar informasi.

✨ Klik atau sentuh setiap kartu perangkat di bawah ini untuk melihat detail penjelasan dan fungsinya:

02. Klasifikasi Perangkat

Jenis-Jenis Perkakas TIK

Berdasarkan fungsi utamanya dalam sistem komputer, perkakas TIK dikelompokkan menjadi 5 kategori utama:

⌨️

INPUT

Memasukkan data/perintah ke komputer.

Keyboard, Mouse, Mic, Kamera, Scanner
⚙️

PROCESSING

Mengolah dan memproses data pusat.

CPU, Processor, VGA Card
🖥️

OUTPUT

Menampilkan hasil olahan data.

Monitor, Printer, Speaker, Proyektor
💾

STORAGE

Menyimpan file dan data permanen.

Flashdisk, Harddisk, SSD, Memory Card
🌐

KOMUNIKASI

Menghubungkan antar jaringan data.

Router, Modem, Access Point, Smartphone

04. Perkembangan & Aplikasi

Perkembangan Perkakas TIK dari Masa ke Masa

Teknologi informasi berkembang sangat cepat. Ukuran perangkat menjadi lebih ringkas, namun kecepatannya makin tinggi dan fungsinya makin beragam.

1. Teknologi Awal

Surat fisik, telegraf, dan koran cetak untuk bertukar pesan terbatas.

2. Telepon Kabel

Memungkinkan komunikasi suara jarak jauh secara langsung.

3. Komputer Generasi Pertama

Berukuran sangat besar seukuran ruangan, memproses kalkulasi angka.

4. Telepon Seluler (HP Monokrom)

Dapat dibawa ke mana saja untuk panggilan suara dan SMS sederhana.

5. Smartphone & Perangkat Cerdas

Perangkat saku serba bisa: internet, kamera jernih, aplikasi pintar, dan multimedia.
